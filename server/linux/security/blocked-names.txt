# edit this file on the server (/etc/lbppc/blocked-names.txt) and it applies at once, no restart.

# Before comparing, a name is lower-cased, leetspeak is undone (0 o, 1 i, 3 e, 4 a, 5 s, 7 t, 8 b, @ a, $ s, ! i,
# | i) and everything but letters is dropped, so F4gg0t, f.a.g.g.o.t and FAGGOT are the same. Each name is also
# checked with repeated letters collapsed (faaaggot -> fagot).
#
#   word    blocked anywhere in a name (use for words with no innocent uses)
#   =word   blocked only as the whole name (short words found inside normal names: rape in grape, nazi in Nazir)
#   +word   an innocent word that contains a blocked one: taken out of the name before checking (badminton, Essex)
#
# Existing accounts are not changed by this list; it only stops new sign-ups.

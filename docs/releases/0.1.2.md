# LBPPC 0.1.2 (hotfix)

## Fixed

- **"Certificate has expired" when creating an account or signing in.** On some PCs, creating an account, signing in
  and the friends list failed with `CERTIFICATE_VERIFY_FAILED ... certificate has expired`, even with the right date
  and time. Windows keeps an old, expired copy of one of the certificates the LBPPC servers use, and the launcher
  picked that copy over the current one. The launcher now carries the current certificates itself, so it connects on
  every PC. Nothing changed for PCs that already worked, and connections are checked as strictly as before.
- **The game stayed in English in most languages.** The US version of LittleBigPlanet 3 only allows English and
  French by itself, so choosing Spanish, German, Russian or most other languages in the launcher still gave you
  English. Every language the game has text for now works: English, French, Spanish (Spain and Latin America),
  German, Italian, Dutch, Portuguese (Portugal and Brazil), Russian, Finnish, Swedish, Danish, Norwegian and Polish.
  Arabic is no longer offered: the game has no Arabic text. If you had chosen it, the language goes back to Automatic.

## Updating

- **From 0.1.1:** the launcher offers this update when it starts. Click **Update**.
- **From 0.1.0:** download this release by hand, unzip it into a new folder, and copy the `user` folder across from
  your old one (and `input.ini` if you changed your controls).

New to LBPPC? See the full guide: https://lbppc.com/getting-started

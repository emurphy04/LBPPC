# LBPPC 0.1.3

## Security

- **Stronger sign-in to the online server.** When the game connects to the level server, it now proves it's you with a
  one-time code from your own LBPPC account sign-in, so nobody else can go online as you, even on the same network.
  Please update: older versions will stop being able to go online once everyone has had time to move to 0.1.3.
- **The game checks it's really talking to the LBPPC servers.** Its secure connection to the level server is now
  verified, so nothing between you and the server can pose as it.
- **Clearer messages when creating an account or signing in.** You're told when a name isn't allowed, when too many
  accounts were made from your network in one day, and when sign-in is paused for a few minutes after too many wrong
  passwords.

## Smoother play

- **Far less stuttering the first time you see something new.** The game used to freeze, sometimes for several
  seconds, the first time it met a new effect or object, most of all in the first level. That work now happens in
  the background, so play keeps going. The first time you see something new it can appear a moment late. If you'd
  rather it freeze than pop in, turn off **Background shader builds** on the launcher's Debug page.

## Fixed

- **Connecting online takes about a second instead of half a minute.** Every time you went online, the game sat on
  the connecting screen for 30 seconds waiting for a network check LBPPC never answered. It now gets its answer
  straight away.
- **Connecting online could load forever.** On some PCs the game couldn't reach the sign-in server ("certificate
  has expired"), for the same reason the launcher couldn't before 0.1.2: Windows keeps an old, expired copy of a
  certificate the LBPPC servers use. The game now carries the current certificates itself, like the launcher.

## Known issue

- Returning to your pod with a friend can occasionally leave you both stuck. We know what triggers it and are
  working on it. If it happens, both players restarting the game gets you going again.

## Updating

- **From 0.1.1 or 0.1.2:** the launcher offers this update when it starts. Click **Update**.
- **From 0.1.0:** download this release by hand, unzip it into a new folder, and copy the `user` folder across from
  your old one (and `input.ini` if you changed your controls).

New to LBPPC? See the full guide: https://lbppc.com/getting-started

# LBPPC 0.1.1

A setup wizard and updates in the launcher, DLC, more languages, save import, and a round of bug fixes.

Coming from 0.1.0? It has no update check, so download this one by hand: unzip it into a new folder, then copy the
`user` folder across from your old one (and `input.ini` if you changed your controls). From here on, the launcher
updates itself.

## New in the launcher

- **Set up your game.** Choose your game folder and its 1.28 update folder, and LBPPC puts the update into your game
  folder for you. It opens by itself the first time, or from the new **Set up...** button next to Browse. It checks
  both folders as you choose them and says what's wrong in plain words.
- **Check files.** LBPPC checks your game's files against a known-good copy of LittleBigPlanet 3 1.28: a quick check
  every time, and a full check (every byte, about a minute) from the button in Set up. A missing or damaged file is
  the most common reason the game won't start.
- **Updates from the launcher.** The launcher checks for a new version when it starts and shows what's new. Click
  **Update** and it downloads it, checks it, and opens again on the new version. Your saves, settings and controls
  are kept.
- **DLC.** Step 3 of Set up adds your own DLC, extracted from your PS4, including LittleBigPlanet and
  LittleBigPlanet 2 packs that came to PS4. This is new: if a costume or kit you own doesn't unlock, tell us on the
  Discord.
- **Import save.** Bring your story progress over from a decrypted PS4 save (the link at the bottom of the launcher).
  Your current LBPPC save is backed up first.
- **Languages.** Pick the game's language in Settings: English, French, Spanish, German, Italian, Dutch,
  Portuguese, Russian, Finnish, Swedish, Danish, Norwegian, Polish or Arabic. The launcher is translated into the same
  languages (Arabic: the game only). The translations are new; fluent speakers on the Discord are checking them.
- **Discord.** While you play, your Discord profile can show that you're playing LittleBigPlanet 3 on LBPPC. Turn it
  off under Online.

## Bug fixes

- **Multiple controllers:** if you have multiple controllers plugged in, the game now follows what controller you're
  actively using, rather than picking one from the start.
- **The launcher looked frozen** at the first start or after choosing a folder: the window that needed an answer
  could end up hidden behind the launcher. It now always stays in front.
- **The friends list could stay on "Signing in..."** when the server was slow to answer. It now says what happened
  and tries again.
- **Online co-op turned off:** copies that keep their system files in a separate `Sc0` folder had online co-op off.
  Set up now adds those files to your game folder.
- **Wrong game version or region:** a copy that isn't the US version 1.28 now stops with a message saying what's
  needed, instead of crashing. The European (PAL) and other versions aren't supported: LBPPC needs the US version.

## Getting started

1. Unzip the release anywhere except Program Files (for example `C:\Games\LBPPC`).
2. Start `LBPPC.exe`. Windows SmartScreen may warn about a new app: **More info**, then **Run anyway**.
3. In **Set up your game**, choose your game folder and its 1.28 update folder (both extracted), then click **Set up**.
4. Press **Play**. The first start prepares the game (about a minute).

Full guide: https://lbppc.com/getting-started

You need your own copy of LittleBigPlanet 3 (US, CUSA00473) and its 1.28 update. This release contains no game files,
and we can't share any information about PKG extractors.

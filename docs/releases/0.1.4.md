# LBPPC 0.1.4

## New

- **The European edition works.** LittleBigPlanet 3 from Europe (CUSA00063) at version 1.28 now runs, as does its
  DLC. The US edition (CUSA00473) works as before.
- **Your game and update folders are never changed.** As in shadPS4, the 1.28 update is now read from its own folder
  when you play, so nothing is copied or moved during setup and the same folders keep working in shadPS4. Setup is
  done the moment you click **Use these folders**.
- **The game log opens in a window of its own**, beside the launcher, instead of making the launcher taller than the
  screen. It opens by itself if the game stops with an error.
- **More than one save file.** Choose a save file under Settings in the launcher, or make a new one to start the
  game from the beginning without losing your progress. Your existing progress is the Main save file. Settings,
  DLC and your online account are shared by all of them. Import save brings a PS4 save into the save file chosen.
- **LittleBigPlanet 2 content for everyone.** Settings > My Unlocks > Unlock LittleBigPlanet 2 Content was crossed
  out unless your account still had LittleBigPlanet 2 progress from PSN. It now works for every player, and brings in
  the objects collected in LittleBigPlanet 2's story. LittleBigPlanet 2 DLC packs still need the DLC installed.
- **Start the game without the launcher.** Click **Shortcut** at the bottom of the launcher for a desktop shortcut
  that goes straight into the game with your launcher settings. The launcher appears only if something needs you,
  such as setup or an error, and closes when you quit the game.
- **Sharper launcher text**, and the launcher opens a little larger on 1080p screens, so small text is easier to read.

## Fixed

- **Radeon cards: the game closing straight away** ("Game exited with 0x00000017") on cards such as the RX 6600 XT,
  RX 6800, RX 7800 XT and RX 7900 XTX. The game now keeps other programs' overlays out (Overwolf, Epic Games and
  Rockstar's, which Windows loads into every game), and when the graphics driver still won't show the game's picture
  the usual way, the game shows it through DirectX instead.
- **Crashes when the game is started from Steam** (as a non-Steam game). Steam's shader pre-caching, which can't
  record this game's graphics and led to crashes in the graphics driver, is now kept out of the game. Steam's overlay
  still works.
- **Crashes on newer Intel processors and under Wine on Linux**, including the crash after the first cutscene and
  crashes when a level loads. These PCs could overwrite some of the game's working memory while handling graphics
  data; the game is now protected from that.
- **Stuck in the first cutscene on Intel processors.** The intro now plays through.
- **Photos, stickers and costume pictures.** Photos you take in the game are saved and show up in your photo album,
  stickers made from them work, and saved costumes get their picture. At render resolutions above 1080p these came
  out as slanted streaks; they're right at every resolution now.
- **Fog in the wrong colour** in some levels.
- **Red and green edges around everything.** A debug view could be switched on by accident in the settings menu, and
  then stayed on every time the game started. It's now off at every start.
- **FSR 3.1 frame generation flicker.** The in-between frames FSR 3.1 makes are steadier.
- **DLC missing in the game when you have a lot of it.** Only the first 64 packs reached the game; now they all do.
- **Editing your profile's About Me froze the menu.** The text box that opens only answered the keyboard's Enter
  and Esc, or some controllers' buttons. Cross now accepts and Circle cancels from any controller.
- **Setup explains what's wrong with your game folders.** Instead of a list of missing files, it says when the
  update folder holds only system files, when the update's files aren't there, or how much of the game a copy cut
  short is missing. Copies whose game program files were saved decrypted are no longer reported as the wrong size.
- **Some copies couldn't go online** when the update folder didn't have its own copy of the game's online files.
  The game's own are used now.
- **The game kept trying to reach a player it couldn't connect to**, many times a second, until you quit. It now
  waits longer between tries and gives up after about a minute.
- **Stop in the launcher froze it** for a few seconds while the game closed.
- **The GPU usage readout showed 0%** on some laptops.
- **Lights didn't light anything.** Lights placed in levels, such as the ones in many community levels, now light
  up their surroundings again, instead of showing for a moment while the level loads and then going dark.

## Known issue

- Returning to your pod with a friend can occasionally leave you both stuck. If it happens, please make a report
  (Make a report in the launcher) on **both** PCs: 0.1.4 records more about the moment it happens, which helps us find
  it.

## Updating

- **From 0.1.1, 0.1.2 or 0.1.3:** the launcher offers this update when it starts. Click **Update**.
- **From 0.1.0:** download this release by hand, unzip it into a new folder, and copy the `user` folder across from
  your old one (and `input.ini` if you changed your controls).
